# Blitz Report Excel Add-in Skills

AI skills for business users of the Blitz Report Excel add-in: Oracle E-Business Suite analysis, period close readiness and upload actions in Claude in Excel and Microsoft 365 Copilot in Excel. Installs and explains the skills; they run in Excel.

Browse with search: https://www.enginatics.com/ai-skills/blitz-report-excel-addin-ai-skills/

```
/plugin marketplace add enginatics/ai-skills
/plugin install blitz-report-excel-addin-ai-skills@enginatics
```

Then run `/blitz-report-excel-addin-ai-skills:excel-skills-setup` to install the skills into Claude in Excel or Microsoft 365 Copilot in Excel, or download a single skill from its page. The skills run in Excel through the Blitz Report Excel add-in.

## Analytics

- [Anomaly Detection](https://www.enginatics.com/ai-skills/br-anomaly-detection/) (`br-anomaly-detection`): Find unusual or suspicious rows in a Blitz Report dataset — outlier transactions, duplicate invoices, abnormal amounts, data-quality errors — using robust statistics, Mahalanobis distance, Benford's Law, and duplicate detection.
- [Clustering](https://www.enginatics.com/ai-skills/br-clustering/) (`br-clustering`): Segment a Blitz Report dataset into natural groups using K-Means or DBSCAN, then profile and name each segment in plain business language.
- [Data Dashboard](https://www.enginatics.com/ai-skills/br-data-dashboard/) (`br-data-dashboard`): Build an interactive dashboard on top of any tabular data sheet — KPI cards, charts, and slicers — without modifying the source columns.
- [Forecasting](https://www.enginatics.com/ai-skills/br-forecasting/) (`br-forecasting`): Forecast a time series from a Blitz Report — future demand, sales, GL trend, AR collections, cash, or inventory — using Excel's native FORECAST.ETS (Holt-Winters) with seasonality detection, confidence intervals, and a backtest accuracy check.
- [RFM Analysis](https://www.enginatics.com/ai-skills/br-rfm-analysis/) (`br-rfm-analysis`): Score customers (or vendors) on Recency, Frequency, and Monetary value from a transactional Blitz Report and map them to named segments like Champions, Loyal, At Risk, and Hibernating.

## Audit and Security

Read-only.
