Blitz Report Excel Add-in Skills

AI skills for business users of the Blitz Report Excel add-in: Oracle E-Business Suite analysis, period close readiness and upload actions in Claude in Excel and Microsoft 365 Copilot in Excel. Installs and explains the skills; they run in Excel.

Install

/plugin marketplace add enginatics/ai-skills
/plugin install blitz-report-excel-addin-ai-skills@enginatics

Then run /blitz-report-excel-addin-ai-skills:excel-skills-setup to install the skills into Claude in Excel or Microsoft 365 Copilot in Excel, or download a single skill below. The skills run in Excel through the Blitz Report Excel add-in.

Skills

Analytics

Anomaly Detection

br-anomaly-detection

Find unusual or suspicious rows in a Blitz Report dataset — outlier transactions, duplicate invoices, abnormal amounts, data-quality errors — using robust statistics, Mahalanobis distance, Benford's Law, and duplicate detection.

Clustering

br-clustering

Segment a Blitz Report dataset into natural groups using K-Means or DBSCAN, then profile and name each segment in plain business language.

Data Dashboard

br-data-dashboard

Build an interactive dashboard on top of any tabular data sheet — KPI cards, charts, and slicers — without modifying the source columns.

Forecasting

br-forecasting

Forecast a time series from a Blitz Report — future demand, sales, GL trend, AR collections, cash, or inventory — using Excel's native FORECAST.ETS (Holt-Winters) with seasonality detection, confidence intervals, and a backtest accuracy check.

RFM Analysis

br-rfm-analysis

Score customers (or vendors) on Recency, Frequency, and Monetary value from a transactional Blitz Report and map them to named segments like Champions, Loyal, At Risk, and Hibernating.

Audit and Security

EBS Audit Trail & Access Review

br-audit-trail

Answer "who changed what, when" across Oracle EBS setups and access: mine the FND Audit Trail reports for setup and profile changes by record and column, correlate with user login history and responsibility assignments, and produce a reviewable change narrative for an audit window or an incident. Read-only.

Instance Diff

br-instance-diff

Compare Oracle EBS instances through Blitz Reports in Excel: run the same report with the same parameters against two configured environments (DEV/TEST/PROD, pre/post-upgrade, source/clone) and explain the differences — row counts, missing and extra keys, changed values by column — or diff the two instances' report catalogs.

Cash Management

Cash Management Reconciliation Readiness

br-ce-recon-readiness

Assess Oracle EBS Cash Management bank reconciliation / period-close readiness in Excel: have the br-run-reports skill extract unreconciled bank statement lines and the GL cash reconciliation, then give a red/amber/green verdict with remediation and build a CE reconciliation-readiness scorecard.

Cash and Working Capital

Cash & Working-Capital Orchestrator

br-cash-working-capital

Orchestrate a full Oracle EBS cash & working-capital review in Excel: run the duplicate-payment recovery, AR collections worklist, and AP payment-run optimizer, cross-check the open duplicate invoices against the recommended pay-run (so you don't pay a duplicate you're about to claw back), then assemble one master scorecard with the total cash opportunity by lever (recover / protect / capture discounts / collect / DPO headroom), a combined net-cash-by-week view, and the ranked cross-lever action list.

Fixed Assets

FA Period Close Readiness

br-fa-close-readiness

Assess Oracle EBS Fixed Assets period-close readiness in Excel: have the br-run-reports skill extract the mass-additions backlog, depreciation/reserve status, and FA-to-GL reconciliation, then give a red/amber/green verdict with remediation and build an FA close-readiness scorecard.

General Ledger

Finish a Spreadsheet Server / GL Wand conversion

br-fsg-conversion-review

Finish a financial statement workbook converted from Spreadsheet Server or GL Wand to Blitz FSG: read its Conversion Log sheet, fix in the workbook what the converter could not (period cells read by other formulas, formula-driven format and segment cells, hierarchy suffixes, unsupported currency types, cells left unconverted), ask the user about the rest, and mark every log line.

GL Account Coding Assistant

br-gl-account-coder

Suggest GL account coding from the ledger's own history: given transactions to code (or re-code), mine GL Account Analysis for how this entity has historically coded the same supplier, source, category or description, and propose the account combination with a confidence level and the precedent shown. Optionally stage approved corrections as a journal via the GL Journal Upload — only on explicit user confirmation.

GL variance analysis
